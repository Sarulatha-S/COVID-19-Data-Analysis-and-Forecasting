# COVID-19 Data Analysis and Forecasting

## Project Overview
This project focuses on analysing COVID-19 pandemic data and understanding the trends in confirmed cases, deaths, and recoveries using Python and data analytics techniques.

## Objective
To explore historical COVID-19 data, identify pandemic trends, analyse daily case patterns, and develop a time-series forecasting workflow for confirmed cases in India.

## Dataset
Johns Hopkins University COVID-19 datasets:
- Global Confirmed Cases
- Global Deaths
- Global Recovered Cases

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Project Workflow
1. Data loading and understanding
2. Data cleaning and preprocessing
3. Data transformation and aggregation
4. Exploratory Data Analysis
5. Daily and weekly trend analysis
6. Moving average calculations
7. Time-series feature engineering
8. Forecasting model development
9. Model evaluation
10. 30-day confirmed-case forecasting for India

## Machine Learning Algorithms
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor

## Model Evaluation
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Project Outcome
Analysed historical COVID-19 trends and developed a 30-day forecasting workflow for confirmed cases in India.
